# Screenshot checklist

Capture at least these states after connecting a test API/database:

- [ ] Public landing page at desktop width
- [ ] Registration form with validation feedback
- [ ] Login page and signed-in dashboard
- [ ] Dashboard after adding one problem, project, and skill
- [ ] Empty-state dashboard for a new account
- [ ] Problems list with search, filters, sorting, and pagination
- [ ] Problem create/edit form and delete confirmation
- [ ] Projects list with status and technology chips
- [ ] Skills list with proficiency and target progress
- [ ] Analytics charts with real account data
- [ ] Mobile navigation and a mobile-friendly record list
- [ ] Unauthenticated protected route and server-unavailable state

Use a dedicated test account and remove any private data before sharing screenshots.
