# Project description

## LinkedIn project description

DevTrack is a full-stack developer career and progress tracker built with React, TypeScript, Java 21, Spring Boot, Spring Security, PostgreSQL, and Flyway. It helps engineers organize DSA practice, portfolio projects, technical skills, and learning targets in one private dashboard. The API uses BCrypt password hashing, short-lived JWTs in HttpOnly cookies, user-scoped data access, request validation, and database migrations. The project includes Docker Compose, OpenAPI/Swagger documentation, Postman requests, integration tests, and GitHub Actions CI.

## Launch-post draft

I built DevTrack to bring my software-engineering growth into one place.

It tracks DSA problems, portfolio projects, technical skills, and learning targets, with a dashboard and analytics based on real saved data. I built it as a React + TypeScript frontend backed by a Java 21 Spring Boot API, PostgreSQL, Flyway, and Spring Security.

The project also includes HttpOnly-cookie authentication, user-scoped CRUD, Docker Compose, OpenAPI documentation, Postman examples, automated tests, and a GitHub Actions workflow.

This was a useful way to practice designing a complete product—not just screens, but also API contracts, persistence, security, testing, and deployment setup.
